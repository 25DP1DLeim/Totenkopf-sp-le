# Totenkopf 'Dokumentācija'

## Galvenā ideja:
Totenkopf ir spēle, kuru iedvesmoja spēle '60 seconds' ar griezeniskiem pretīgiem vizuāliem, kurus iedvesmoja Garry's mod gamemode "Industrial Nightmare: Liver failure"

Galvenā spēles valūta ir kauli.

Lai darbs ietu raitāk, var eksplautēt lētu darbaspēku - proleteriātus.

Lai darbs būtu efektīvāk, var nopirkt darbiniekiem labākas mašīnas. Šīs mašīnas padara darbu nedrošāku un var novest pie proleteriātu nāvēm. Lai no tā izvairītos, var nopirkt drošības sistēmas.

Ar laiku arī sāks parādīties leģionari, kuri veiks sabotāžu.

Lai tiktu vaļā no tiem, var iegādāties kontrolierus.
